# Island Player

Динамический островок с музыкой сверху экрана для Windows 10 и 11.
Играет музыку из Яндекс Музыки, ВКонтакте и Spotify и показывает всё, что играет в Windows (YouTube, браузер, другие плееры).

## Как получить установщик (один раз, без командной строки)

Установщик собирается автоматически в облаке GitHub.

1. Зарегистрируйтесь на [github.com](https://github.com) и создайте новый репозиторий (Public, чтобы установщик мог скачать любой).
2. На странице репозитория нажмите **uploading an existing file** и перетащите туда всё содержимое распакованной папки,
   включая папку `.github`. Нажмите **Commit changes**.
3. Откройте **Releases**, затем **Create a new release**. В поле Tag впишите `v1.2.0` и нажмите **Publish release**.
4. Подождите около 10 минут. Ход сборки виден на вкладке **Actions**. Когда она закончится (зелёная галочка),
   на странице релиза появится файл **Island-Player-Setup.exe**.

Для следующих версий меняйте номер в теге (`v1.2.1`, `v1.3.0`). Собрать вручную без релиза можно так:
**Actions**, затем «Сборка установщика», затем **Run workflow**. Готовый файл будет в разделе Artifacts запуска.

## Как установить

Скачайте `Island-Player-Setup.exe` со страницы Releases и запустите. Мастер на русском предложит выбрать папку установки.
На последней странице можно поставить галочки «Запустить Island Player» и «Создать ярлык на рабочем столе».
Ярлык в меню «Пуск» создаётся всегда, а закрепить программу на панели задач можно оттуда правой кнопкой мыши
(Windows не позволяет делать это программно).

Установщик не подписан сертификатом, поэтому Windows может показать окно «Windows защитил ваш компьютер».
Нажмите **Подробнее**, затем **Выполнить в любом случае**.

## Как пользоваться

- При запуске открываются настройки. Кнопка в правом верхнем углу сворачивает программу в островок.
- Клик по островку раскрывает плеер. Стрелка вверх сворачивает его, кнопка с ползунками открывает настройки.
- Крестик в настройках прячет программу в трей. Меню трея: настройки, островок, пауза, следующий трек, выход.
- Островок показывает то, что запустилось последним: свою музыку или чужое приложение. Кнопки управляют тем, что показано.
  Когда вы запускаете свою музыку, чужая ставится на паузу.
- В настройках: ширина островка, отступ от верха, автозапуск, визуализация, музыка из других приложений.

## Вход в аккаунты (один раз)

Хранится только токен, зашифрованный средствами Windows.

**Яндекс Музыка.** Кнопка «Войти через Яндекс». Для полных треков нужна подписка Плюс.

**ВКонтакте.** Кнопка «Войти через ВКонтакте» открывает настоящую страницу входа. Код из SMS и капчу обработает сам ВК,
пароль программа не видит. Вход неофициальный (как у сторонних клиентов), поэтому ВК может его ограничить.
Если окно не сработало, вставьте токен вручную.

**Spotify.** Нужна подписка Premium и свой Client ID:
1. Откройте <https://developer.spotify.com/dashboard> и создайте приложение.
2. Redirect URI: `http://127.0.0.1:38123/callback`
3. Отметьте Web API и Web Playback SDK.
4. Вставьте Client ID на вкладке «Аккаунт» и нажмите «Войти».

В режиме Development Mode Spotify отдаёт список треков только ваших плейлистов. Чужие плейлисты
играют кнопками «Слушать» и «Вперемешку», но без списка.

## Если что-то не работает

- **Сборка в Actions красная.** Откройте запуск, затем шаг с ошибкой, и пришлите текст из него.
- **Spotify: плеер не запустился.** Нужен Widevine, он скачивается при первом запуске. Если в установленной
  версии Spotify молчит, потребуется VMP-подпись ([инструкция castlabs](https://github.com/castlabs/electron-releases/wiki/EVS)).
- **Яндекс или ВК: трек не грузится.** Оба сервиса работают через неофициальный API, он может меняться.
- **Музыка из других приложений не видна.** Убедитесь, что переключатель включён в настройках. Работает через
  встроенный в Windows PowerShell 5.1.

## Структура

```
.github/workflows/   облачная сборка установщика
build/installer.nsh  страница мастера установки с ярлыком на рабочем столе
assets/              иконка
scripts/             загрузка Electron для сборки
src/main/            окна, трей, хранилище, клиенты сервисов, мультимедиа Windows
src/renderer/        скрытый плеер, островок, настройки
```
